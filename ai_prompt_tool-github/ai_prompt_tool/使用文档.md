# AI 提示词工具 使用文档

## 一、简介

本工具是一个 PyQt 桌面应用，用于与 AI 模型网页版（免费版）配合完成工作流任务。核心功能是：

1. **生成提示词**：根据用户需求描述，自动生成包含 7 种操作指令标记的提示词，交给 AI 使用
2. **导入并执行**：将 AI 的回复粘贴回工具，工具自动解析其中的操作指令并执行（创建/修改/删除文件、访问网页、下载内容等）
3. **语言切换**：支持中 / 英界面切换，提示词、规则文档、目录文档均按当前语言生成

---

## 二、环境安装

### 系统要求
- Python 3.8 及以上版本
- 操作系统：Windows / macOS / Linux

### 安装依赖

```bash
cd ai_prompt_tool
pip install -r requirements.txt
```

依赖说明：
| 依赖 | 用途 |
|------|------|
| PyQt5 | 图形界面 |
| requests | 网页访问与文件下载 |

### 启动工具

```bash
cd ai_prompt_tool
python main.py
```

启动后弹出主窗口，包含两个标签页：
- **生成提示词**
- **导入并执行**

## 三、标签页一：生成提示词

### 界面说明

| 区域 | 说明 |
|------|------|
| 需求描述输入框 | 用自然语言描述你要 AI 做的事，例如"帮我创建一个 Python 项目，包含 main.py 和 config.py" |
| 生成提示词按钮 | 根据输入的需求，生成完整提示词显示在下方输出区 |
| 下载规则文档按钮 | 弹出文件保存对话框，将纯文本规则文档（.txt）保存到本地 |
| 下载目录文件内容按钮 | 将当前工作目录内所有文件内容汇总为一个 .txt 文档，供 AI 作为上下文参考 |
| 复制提示词按钮 | 将输出区的提示词复制到系统剪贴板 |
| 提示词输出区（只读） | 显示生成的提示词 |
| 规则文档预览区（只读） | 显示规则文档内容 |

### 操作步骤

1. 点击 **选择目录**，先指定工作目录（生成提示词、下载目录文件内容前都需要）
2. 在"需求描述"输入框中填写需求
3. 点击 **生成提示词**，下方输出区显示完整提示词
4. 点击 **复制提示词**，将提示词粘贴到 AI 网页版对话框中
5. （可选）点击 **下载规则文档** 和/或 **下载目录文件内容**，保存 .txt 文件后作为附件发给 AI，帮助 AI 更好地遵循格式并了解现有文件

> 提示：如果 AI 没有按要求输出标记格式，可以把规则文档发给 AI 让它重新生成。

## 四、标签页二：导入并执行

### 界面说明

| 区域 | 说明 |
|------|------|
| AI 回复输入框 | 粘贴 AI 回复的完整内容 |
| 工作目录标签 | 显示当前选择的工作目录，默认是当前目录 |
| 选择目录按钮 | 弹出目录选择器，指定操作的工作目录 |
| 解析并执行按钮 | 解析 AI 回复中的指令并逐条执行 |
| 仅解析预览按钮 | 只解析不执行，显示找到的指令列表 |
| 清除按钮 | 清空输入框和结果区 |
| 执行结果区（只读） | 逐条显示执行结果（✅ 成功 / ❌ 失败 + 原因） |

### 操作步骤

1. 将 AI 回复的完整内容粘贴到输入框
2. 点击 **选择目录**，指定操作的工作目录（所有相对路径以此目录为基准）
3. 点击 **仅解析预览**，确认解析出的指令是否符合预期
4. 确认无误后，点击 **解析并执行**
   - 若指令包含文件写入/删除操作，会弹出确认对话框，需手动确认后才执行
5. 查看执行结果区，每条指令显示 ✅ 或 ❌ + 原因

> 提示：如果校验失败，结果区会显示"请让 AI 按规则重新生成"，把错误信息反馈给 AI 即可。

### 安全机制

| 机制 | 说明 |
|------|------|
| 工作目录校验 | 执行前检查工作目录是否有效（已选择且存在），否则拒绝执行 |
| 执行前确认 | 含写入/删除操作的指令，执行前弹窗确认，避免误操作 |
| 编辑自动备份 | 执行 `EDIT` 修改文件前，自动将原文件备份为 `原文件名.bak`，可手动恢复 |
| 删除不可撤销 | `DELETE` 操作直接删除文件，无备份，请谨慎 |
| 路径越界警告 | 相对/绝对路径超出工作目录时，结果会附"警告: 路径超出工作目录范围"，但仍会执行 |
| 异常兜底 | 单条指令执行抛出异常时不会中断整体流程，仅标记该条失败 |

## 五、指令标记格式（共 7 种）

AI 回复中使用以下标记来描述操作，工具解析后逐条执行：

| 标记 | 含义 | 格式 | 示例 |
|------|------|------|------|
| `[CREATE: 路径]` ... `[/CREATE]` | 新建文件 | 标记内为文件内容 | `[CREATE: output/hello.txt]` |
| `[EDIT: 路径]` ... `[/EDIT]` | 修改现有文件（全量替换） | 标记内为完整新内容 | `[EDIT: config.json]` |
| `[DELETE: 路径]` | 删除文件（单行，无闭合） | 单独一行 | `[DELETE: temp/old.txt]` |
| `[URL: 网址]` | 访问网页（单行，无闭合） | 网址必须以 http/https 开头 | `[URL: https://example.com]` |
| `[DOWNLOAD: 网址]` ... `[/DOWNLOAD]` | 下载文件 | 标记内第二行为保存路径 | `[DOWNLOAD: https://example.com/a.png]` |
| `[CODE: 文件名]` ... `[/CODE]` | 保存代码 | 标记内为代码内容 | `[CODE: main.py]` |
| `[DATA: 类型]` ... `[/DATA]` | 保存结构化数据 | 标记内为 JSON 或 CSV | `[DATA: JSON]` |

### 完整示例

以下是一段符合规则的 AI 回复示例：

```
我来帮你完成项目初始化。

[CREATE: project/README.md]
# 项目说明
这是自动生成的项目文档。
[/CREATE]

[CREATE: project/main.py]
print("Hello World")
[/CREATE]

[EDIT: project/config.json]
{"name": "my_project", "version": "1.0.0"}
[/EDIT]

[DELETE: project/old_temp.txt]

[URL: https://httpbin.org/get]

[DOWNLOAD: https://httpbin.org/image/png]
project/assets/logo.png
[/DOWNLOAD]

[CODE: project/utils.py]
def hello():
    return "hi"
[/CODE]

[DATA: JSON]
{"status": "ok", "created": 3, "deleted": 1}
[/DATA]

以上操作已完成。
```

## 六、校验规则

工具在解析 AI 回复时会进行以下校验，不符合则报错并提示让 AI 重新生成：

| 校验项 | 说明 |
|--------|------|
| 标记闭合 | 成对标记（CREATE/EDIT/DOWNLOAD/CODE/DATA）必须有对应的 `[/标记]` |
| 参数非空 | 标记内的路径/URL 不能为空 |
| URL 格式 | `[URL:]` 和 `[DOWNLOAD:]` 的参数必须以 `http://` 或 `https://` 开头 |
| DATA 合法性 | `[DATA:]` 内容必须是合法 JSON 或 CSV |
| 至少一条指令 | 回复中至少要包含一个指令标记 |

校验失败时，工具会指出具体行号和原因，例如：
- `❌ 第 5 行: [CREATE:] 标记未闭合，请让 AI 重新生成`
- `❌ 第 12 行: [URL:] URL 格式无效，请让 AI 重新生成`

---

## 七、路径安全说明

- **相对路径**：相对于工作目录解析（通过"选择目录"按钮设置）
- **绝对路径**：超出工作目录时工具会发出警告，但仍会执行
- 所有操作（创建/编辑/删除文件、下载保存）都在本地文件系统执行
- **编辑保护**：执行 `EDIT` 前自动备份原文件为 `.bak`，误操作可用备份恢复

> 注意：执行前请确认工作目录设置正确，避免误操作生产目录。

## 八、常见问题

**Q: AI 回复格式不对，工具报错怎么办？**
A: 把工具显示的错误信息（行号 + 原因）复制给 AI，让它按规则重新生成。也可以把"下载规则文档"生成的 .txt 文件发给 AI 作为参考。

**Q: 执行后文件保存在哪里？**
A: 保存在"工作目录"中。相对路径相对于工作目录，绝对路径直接使用。

**Q: 下载文件失败怎么办？**
A: 工具会显示下载失败原因（网络超时、HTTP 状态码 ≥ 400 等）。检查网络或 URL 是否正确后重试。

**Q: 可以撤销执行吗？**
A: 工具没有全局撤销功能。但 `EDIT` 操作会自动备份原文件为 `.bak`，可用备份恢复；`DELETE` 不可撤销。执行前请先用"仅解析预览"确认指令内容，并注意执行前的确认对话框。

**Q: 支持哪些 AI 模型？**
A: 支持所有能输出文本的 AI 网页版，只要 AI 能按标记格式回复即可。推荐使用支持长文本输出的模型。
